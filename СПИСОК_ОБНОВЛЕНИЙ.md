# Список обновлений — Moewshare Engine

## [Версия 0.1.0-events] — Визуальная система событий и поддержка Кликеров

### 🚀 Новые возможности

#### 1. Окно настроек движка (Preferences) и встроенный AI & MCP Сервер
- **Отдельное окно настроек:** В меню `Файл ➔ ⚙️ Настройки движка…` (сочетание `Ctrl+,` / `Cmd+,`) и в верхней панели инструментов добавлена кнопка **`⚙️ Настройки`**, открывающая окно конфигурации движка.
- **Вкладка «🤖 AI & MCP Сервер»:**
  * Позволяет включить встроенный в редактор локальный **MCP Сервер** (по умолчанию порт `45124`), слушающий по протоколу JSON-RPC 2.0 / Streamable HTTP (`/mcp` и `/status`).
  * **Авто-подключение к Antigravity в 1 клик:** Кнопка `⚡ Подключить к Antigravity` автоматически настраивает файл `~/.gemini/config/mcp_config.json`, регистрируя Moewshare как MCP сервер.
  * **Копирование конфига для Claude Code / Cursor:** Кнопка `📋 Скопировать JSON` мгновенно копирует готовый блок конфигурации в буфер обмена.
  * **Live MCP Request Log:** В окне настроек в реальном времени отображаются поступающие вызовы от AI-ассистента (`moewshare_create_object`, `moewshare_add_event_node`, `moewshare_connect_nodes` и т.д.).
- **14 специализированных MCP-инструментов управления редактором:**
  * `moewshare_get_status` — состояние редактора, активная сцена, запущен ли тест.
  * `moewshare_get_scene` — получение полного списка объектов, координат, компонентов и свойств.
  * `moewshare_create_object` — создание 3D примитивов, UI кнопок, текста, спрайтов и персонажей.
  * `moewshare_update_object` — перемещение, изменение масштаба, вращения, цвета и текста.
  * `moewshare_delete_object` — удаление объектов со сцены.
  * `moewshare_select_object` — выбор объекта в иерархии и инспекторе.
  * `moewshare_add_component` — добавление коллайдеров, физики и контроллеров на объекты.
  * `moewshare_get_event_graph` — инспекция нод, соединений и переменных.
  * `moewshare_add_event_node` — добавление блоков логики на холст сцены или объекта.
  * `moewshare_connect_nodes` — соединение портов нод проводами данных и потока.
  * `moewshare_add_variable` — создание числовых, строковых и логических переменных.
  * `moewshare_run_game` / `moewshare_stop_game` — запуск и остановка симуляции.
  * `moewshare_save_project` — сохранение сцены и проекта.
  * `moewshare_get_console_logs` — чтение ошибок и логов консоли движка.
- **Python Stdio Bridge:** Создан скрипт `scripts/moewshare_mcp_bridge.py`, обеспечивающий 100% совместимость с MCP-клиентами, работающими через stdio-транспорт.
- **Вкладка «📁 Общие»:** Настройки интервала автосохранения, отображения координатной сетки и привязки к сетке (Snap to Grid).
- **Вкладка «🎮 Рендер и физика»:** Настройки лимита FPS (30/60/120/без лимита) и сглаживания (Anti-Aliasing).

#### 2. Инспектор свойств выбранного блока («Свойства»)
- **Панель настройки параметров ноды:** В левой боковой панели редактора событий появилась вкладка **«Свойства»**. При клике по любому блоку на полотне редактор автоматически открывает его настройки.
- **Выбор целевого UI-текста из списка:** В блоке `Set UI Text` больше не нужно гадать имя элемента — появился выпадающий список со всеми текстовыми объектами на сцене (`ScoreText`, `DpsText`, `Text` и др.).
- **Постоянные Префикс и Суффикс текста:** В `Set UI Text` добавлены поля **«Постоянный префикс»** (например, `Монет: ` или `Счёт: `) и **«Постоянный суффикс»** (например, ` шт.` или ` /сек`) с живым предпросмотром результата на экране (`«Монет: 100»`).
- **Бейджи на самом блоке:** На полотне под портами блока `Set UI Text` теперь наглядно пишется, какой именно текст обновляется и какой префикс используется (`🎯 Цель: ScoreText | "Монет: "`).
- **Привязка к конкретным кнопкам:** На глобальном графе события клика кнопок теперь строго фильтруются по `ButtonName` (клик по кнопке A активирует только цепочку для кнопки A).

#### 2. Интерактивное редактирование и межобъектные переменные
- **Прямое изменение значений и имён:** Во вкладке «Переменные» теперь у каждой переменной есть удобные поля ввода прямо в списке. Больше не нужно удалять переменную, чтобы изменить её стартовое значение (`DefaultValue`), тип (`Integer`, `Float`, `Boolean`, `String`) или имя!
- **🌐 Переменные сцены (с других объектов):** Если переменные созданы в одном объекте (например, `Score` и `ClickPower` в первой кнопке), они автоматически отображаются в разделе **«🌐 Переменные сцены»** во всех остальных кнопках и объектах с быстрыми кнопками `[ + Get ]` и `[ + Set ]`!
- **Единый разделяемый контекст выполнения:** Значения переменных теперь сохраняются и изменяются синхронно по всей сцене — если кнопка улучшения списывает `Score` или увеличивает `ClickPower`, это сразу же видят все остальные кнопки и счётчики игры.
- **Автоматическая привязка локального клика:** На графе объекта событие клика (`On UI Button Clicked` / `On Object Clicked`) теперь автоматически привязывается именно к этому объекту без необходимости выбирать его имя в выпадающем списке.
- **Новые логические блоки:** Добавлены блоки `≥ Greater or Equal (A >= B)` (для проверки баланса монет), `≤ Less or Equal (A <= B)` и `≠ Not Equal (A != B)`.
- **Авто-сохранение изменений:** Изменения значений сразу же помечают проект изменённым (`IsDirty`) и вступают в силу.

#### 2. Глобальные события сцены и события конкретных объектов (Global & Per-Object Event Graphs)
- **Индивидуальный граф у каждого объекта:** Теперь к любому объекту сцены (`SceneObject`) можно привязать свой независимый визуальный граф логики (`EventGraph`).
- **Быстрый переход из Инспектора:** В инспекторе выбранного объекта добавлена кнопка **`⚡ Редактировать граф объекта`**.
- **Бейдж и переключатель таргета:** В верхней панели редактора событий отображается текущий контекст — `🌐 Глобальный граф сцены` или `📦 Граф объекта: [Имя]`, с возможностью в один клик вернуться к глобальному графу.
- **Двухуровневое исполнение (Runtime):** C# движок (`EventRuntime`) и Web/HTML5 рантайм (`moewshare-runtime.js`) теперь параллельно обрабатывают события уровня сцены и события каждого отдельного объекта.

#### 2. Специализированные блоки для кликеров и интерактива
- **`👆 On UI Button Clicked` (`event_ui_button_clicked`):** Срабатывает при нажатии на UI кнопку с указанным ID/именем.
- **`🖱️ On Object Clicked` (`event_object_clicked`):** Срабатывает при клике мыши или тапе по объекту в 3D/2D сцене с использованием Raycasting.
- **`⏱️ On Timer Tick` (`event_timer`):** Ежесекундный таймер (1.0 сек) для механик пассивного дохода, автокликеров и обратного отсчёта.
- **Вкладка каталога «Блоки»:** В левой боковой панели редактора событий появилась удобная вкладка со списком всех категорий, поиском и спавном блока в один клик без выпадающих меню.

#### 3. Встроенный шаблон «Clicker Game»
- В список стартовых шаблонов добавлен готовый кликер с настроенным UI (счётчик, кнопка клика, кнопка апгрейда) и скомпилированным графом событий.

### 🐛 Исправления ошибок

1. **Исправлен двойной клик (+2 вместо +1):**
   - Устранено дублирование вызова событий при нажатии на UI-кнопку: теперь один клик мыши или касание экрана строго один раз триггерит цепочку выполнения (+1).
2. **Исправлен вылет при нажатии «+ Добавить блок»:**
   - **Причина:** В Avalonia 11 элементы `Flyout` отображаются в изолированном окне `OverlayPopupHost`, где конструкция `$parent[UserControl]` внутри шаблона вызывала критическое исключение `System.ArgumentException: Unable to resolve type vm:EventGraphVM`.
   - **Решение:** Обработчики вынесены в надёжные прямые события C# code-behind, а также добавлен стационарный каталог блоков в боковой панели.
2. **Безопасная типизация переменных (`var_set`):**
   - Устранено падение при передаче чисел с плавающей точкой в целочисленные переменные (добавлено автоматическое приведение типов `double` ➔ `int`).
3. **Совместимость портов результатов:**
   - Метод `FindOutput` теперь поддерживает псевдонимы портов (`out_result`, `out_val`, `out_str`, `out_res`), что предотвращает разрывы связей при компиляции математических выражений.
