# Руководство по визуальной системе событий и созданию Кликера в Moewshare Engine

Добро пожаловать в визуальную систему программирования **Moewshare Event System**! С её помощью вы можете создавать полноценную игровую логику, правила, механики и интерактивность без единой строчки кода — соединяя блоки и настраивая переменные в милом и удобном интерфейсе.

---

## 1. Архитектура: Глобальные события сцены vs События объектов

В Moewshare Engine логика разделена на два уровня:

### 🌐 Глобальный граф сцены (Global Scene Graph)
- **Что это:** Управляет общими правилами уровня, подсчётом глобального счёта, таймерами раунда, спавном волн врагов, сменяемостью уровней и общей фоновой музыкой.
- **Как открыть:** Перейдите во вкладку **«События»** на верхней панели редактора. Если ни один объект не выбран для редактирования графа, отображается глобальный граф сцены (вверху горит бейдж `🌐 Глобальный граф сцены`).

### 📦 Граф конкретного объекта (Object-Level Graph)
- **Что это:** Логика, привязанная к конкретному объекту сцены (например, поведение врага, подбираемая монетка, дверь с ключом, кнопка-маскот кликера).
- **В чём преимущество:** Объект несёт свою логику вместе с собой. При вызове действий над собой (`self`) или клике по этому объекту (`event_object_clicked`), блок срабатывает именно для этого экземпляра.
- **Как открыть:**
  1. Выберите любой объект в Иерархии (слева).
  2. В Инспекторе (справа) нажмите розовую кнопку **`⚡ Редактировать граф объекта`**.
  3. Вкладка «События» сразу переключится на граф этого объекта, а в заголовке появится бейдж `📦 Граф объекта: [Имя]`.
  4. Чтобы вернуться к глобальному графу, нажмите кнопку **`🌐 К глобальному графу`** на верхней панели.

## 2. Интерфейс редактора графов

1. **Рабочее полотно:**
   - **Перемещение (Pan):** Зажмите среднюю кнопку мыши (колёсико) или правую кнопку мыши и двигайте мышь.
   - **Масштабирование (Zoom):** Вращайте колёсико мыши.
   - **Перетаскивание нод:** Зажмите левую кнопку мыши на заголовке ноды и перемещайте её.
   - **Выделение:** Кликните по ноде, чтобы выделить её.
2. **Соединение портов:**
   - Потяните мышью от кружочка выхода (справа на блоке) к кружочку входа (слева на другом блоке).
   - Белые порты стрелочек (`▶`) — это поток выполнения (Execution Flow).
   - Цветные кружочки — это данные (Синий = Число, Жёлтый = Строка, Зелёный = Логический булеан, Фиолетовый = Вектор).
3. **Левая панель (Инспектор графа):**
   - **Вкладка «Переменные»:** Создание переменных графа (`int`, `float`, `bool`, `string`). Нажмите **`+ Переменная`**, введите имя и значение по умолчанию. Кнопками **`Get`** и **`Set`** можно мгновенно выставить ноды чтения и записи на полотно!
   - **Вкладка «Свойства»:** Показывает параметры выбранной ноды.
   - **Вкладка «Блоки»:** Каталог всех доступных блоков с быстрым поиском. Клик по блоку спавнит его прямо в центре экрана!
4. **Верхняя панель:**
   - **`+ Добавить блок`** — вызов удобного меню добавления блоков.
   - **`Переменные`** — открыть/скрыть боковую панель переменных.
   - **`Проверить`** — диагностика графа (проверка циклов, висящих проводов).
   - **`Сетка`** — включение/отключение привязки к сетке.
   - **`Сбросить вид`** — центрирование камеры полотна.

## 3. Каталог основных блоков

### ⚡ События (Events)
- **On Begin Play (`event_begin_play`):** Срабатывает один раз при запуске игры. Идеально для инициализации жизней, стартового счёта и UI.
- **On Update (`event_update`):** Вызывается каждый кадр игры. Содержит выход `DeltaTime`.
- **On Timer Tick (`event_timer`):** Срабатывает каждую секунду (1.0 сек). Идеально для пассивного дохода кликера, обратного отсчёта и таймеров.
- **On Key Down / Up (`event_key_down`, `event_key_up`):** Срабатывает при нажатии или отпускании клавиши клавиатуры (Space, W, A, S, D, E и т.д.).
- **On Collision Enter / Exit (`event_collision_enter`, `event_collision_exit`):** Срабатывает при столкновении физических коллайдеров. Выдаёт имя столкнувшегося объекта (`Other`).
- **On Object Clicked (`event_object_clicked`):** Срабатывает, когда игрок кликает мышью (или тапает пальцем) по данному объекту в 3D/2D мире.
- **On UI Button Clicked (`event_ui_button_clicked`):** Срабатывает при нажатии на UI кнопку с указанным идентификатором/именем.

### 📦 Переменные (Variables)
- **Get Variable (`var_get`):** Получить текущее значение переменной графа.
- **Set Variable (`var_set`):** Записать новое значение в переменную. Имеет вход выполнения `▶`, вход нового значения и выход `▶` для продолжения цепочки.
- **🌐 Переменные сцены (с других объектов):** Переменные, созданные в одной кнопке (например, `Score` и `ClickPower`), автоматически видны во всех других кнопках сцены в разделе **«🌐 Переменные сцены»** с быстрыми кнопками `[ + Get ]` и `[ + Set ]`!

### 🔀 Поток выполнения и Логика
- **Branch (If / Else) (`flow_branch`):** Разветвляет выполнение на ветку `True` или `False` в зависимости от входного логического условия (`Condition`).
- **Sequence (`flow_sequence`):** Последовательно выполняет ветку `Затем 0`, затем `Затем 1`, затем `Затем 2`.
- **Greater or Equal (`logic_greater_equal` / `A >= B`):** Проверяет, хватает ли монет на покупку (`Score >= UpgradeCost`).
- **Compare & Logic (`logic_equal`, `logic_not_equal`, `logic_greater`, `logic_less`, `logic_less_equal`, `logic_and`, `logic_or`, `logic_not`):** Все стандартные операции сравнения и логики.

### 🧮 Математика
- **Add / Subtract / Multiply / Divide (`math_add`, `math_sub`, `math_mul`, `math_div`):** Арифметические операции над числами.

### 🎮 Действия и UI
- **Set UI Text (`action_ui_set_text`):** Находит UI элемент по имени (`TargetName`) и обновляет его текстовое содержимое (`Text`). Поддерживает встроенные **Префикс** (например, `Монет: `) и **Суффикс** (например, ` /с`) — число автоматически соединяется со строкой без дополнительных блоков форматирования! Выбрать целевой текст можно прямо из выпадающего списка в панели «Свойства».
- **Play Sound (`action_play_sound`):** Воспроизводит аудиоклип.
- **Destroy Object (`action_destroy`):** Удаляет объект из сцены.
- **Set Transform (`action_set_transform`):** Изменяет координаты позиции, поворота или масштаба объекта.
- **Spawn Object (`action_spawn_object`):** Создаёт новый экземпляр объекта в указанной точке мира.
- **Print / Debug Log (`debug_log`):** Выводит отладочное сообщение в консоль движка.

## 4. Пошаговый туториал: Создание игры «Кликер с апгрейдами»

Давайте с нуля соберём полноценный кликер с очками за клик, пассивным доходом каждую секунду и магазином апгрейдов!

### Шаг 1. Подготовка сцены и UI
1. В иерархии объектов добавьте **Канвас (UI Canvas)**.
2. Внутри Канваса создайте:
   - Текстовый блок с именем `ScoreText` (текст по умолчанию: `Печеньки: 0`).
   - Кнопку с именем `ClickerBtn` (текст: `КЛИК! 🍪`).
   - Кнопку с именем `UpgradeBtn` (текст: `Купить улучшение (Цена: 10)`).
   - Текстовый блок с именем `DpsText` (текст: `В секунду: 0`).
3. *(По желанию)* Добавьте в центр 3D сцены модель или спрайт маскота (например, нашего котика) с именем `CatMascot`.

---

### Шаг 2. Создание переменных
Откройте вкладку **«События»**. В левой панели «Переменные» нажмите **`+ Переменная`** и создайте 4 переменные:
1. `Score` (Тип: `Integer`, Начальное значение: `0`) — текущий баланс игрока.
2. `ClickPower` (Тип: `Integer`, Начальное значение: `1`) — сколько очков даёт один клик.
3. `PassiveIncome` (Тип: `Integer`, Начальное значение: `0`) — сколько очков капает автоматически каждую секунду.
4. `UpgradeCost` (Тип: `Integer`, Начальное значение: `10`) — стоимость апгрейда силы клика.

---

### Шаг 3. Логика старта (Begin Play)
При старте игры отобразим начальные значения на экране:
1. Добавьте ноду **`On Begin Play`**.
2. Добавьте ноду **`Set UI Text`**:
   - В поле `TargetUI` укажите `ScoreText`.
   - В поле `Text` укажите `Печеньки: 0`.
3. Соедините выход `▶` блока `On Begin Play` со входом `▶` блока `Set UI Text`.

---

### Шаг 4. Логика клика (Клик по кнопке или котику)
1. Добавьте ноду **`On UI Button Clicked`**:
   - В поле `ButtonId` впишите имя кнопки: `ClickerBtn`.
2. *(Альтернатива для клика по 3D/2D котику)*: если хотите кликать по самому объекту на сцене, откройте граф котика через Инспектор и используйте блок **`On Object Clicked`**!
3. Добавьте блоки:
   - **`Get Variable`** (переменная `Score`).
   - **`Get Variable`** (переменная `ClickPower`).
   - **`Add`** (`math_add`): соедините выход `Score` со входом `A`, а `ClickPower` со входом `B`.
   - **`Set Variable`** (переменная `Score`): соедините выход суммы `Result` со входом значения `Value`.
4. Соедините `▶` блока `On UI Button Clicked` с `▶` блока `Set Variable (Score)`.
5. Добавьте блок **`Set UI Text`**:
   - В поле `TargetUI` укажите `ScoreText`.
   - Соедините выход обновлённого значения `Score` с портом `Text` (число автоматически сконвертируется в строку!).
   - Соедините `▶` из `Set Variable` в `▶` блока `Set UI Text`.
6. *(Эффекты)*: подключите ноду **`Play Sound`** с приятным звуком «мяу» или клика!

---

### Шаг 5. Покупка улучшения локально на кнопке (Upgrade System)

Если у вас логика пишется **локально на каждой кнопке**:
- На первой кнопке (`ClickButton`) созданы переменные `Score` (монеты) и `ClickPower` (сила клика).
- Во второй кнопке (`UpgradeButton`) мы хотим списать монеты, увеличить силу клика и повысить цену улучшения.

#### 1. Открываем граф кнопки прокачки
1. Выберите вторую кнопку (`UpgradeButton`) в Иерархии.
2. В Инспекторе справа нажмите **`⚡ Редактировать граф объекта`**.

#### 2. Доступ к переменным первой кнопки
1. В левой панели перейдите во вкладку **«Переменные»**.
2. В разделе **«🌐 Переменные сцены»** вы увидите `Score` и `ClickPower`!
3. Нажмите кнопку **`[ + Get ]`** рядом с `Score` и `ClickPower`, а также **`[ + Set ]`** рядом с ними — нужные блоки сразу появятся на холсте!
4. В разделе **«Локальные переменные»** нажмите **`+ Переменная`** и создайте `UpgradeCost` (Тип: `Integer`, значение по умолчанию: `10`).

#### 3. Схема нодов прокачки:
1. Добавьте блок события **`On UI Button Clicked`** (он автоматически привязан к кнопке прокачки!).
2. Добавьте блок **`≥ Greater or Equal (A >= B)`**:
   - Вход `A` соедините с выходом `Значение` блока `Get Variable: Score`.
   - Вход `B` соедините с выходом `Значение` блока `Get Variable: UpgradeCost`.
3. Добавьте блок **`Branch`** (Условие):
   - Вход `Вход` (`▶`) соедините с выходом `Клик` (`▶`) блока `On UI Button Clicked`.
   - Вход `Условие` соедините с результатом `Результат` блока `≥ Greater or Equal`.
4. Ветка **`True (Да)`** (денег хватает):
   - **Списание монет:**
     * Блок **`➖ Subtract (A - B)`**: `A` = `Score`, `B` = `UpgradeCost`.
     * Блок **`Set Variable: Score`**: соедините `Result` вычитания со входом `Новое значение`.
     * Вход `▶` блока `Set Variable: Score` подключите к `True (Да)` блока `Branch`.
   - **Увеличение силы клика:**
     * Блок **`➕ Add (A + B)`**: `A` = `ClickPower`, `B` = `1`.
     * Блок **`Set Variable: ClickPower`**: соедините сумму со входом `Новое значение`.
     * Соедините `▶` от предыдущего `Set Score` к `Set ClickPower`.
   - **Увеличение цены следующего улучшения:**
     * Блок **`✖ Multiply (A * B)`**: `A` = `UpgradeCost`, `B` = `2` (или через `Add` прибавьте `10`).
     * Блок **`Set Variable: UpgradeCost`**: сохраните новую стоимость.
     * Соедините `▶` в `Set UpgradeCost`.
   - **Обновление интерфейса:**
     * Блок **`Set UI Text`**: выберите в свойствах объект текста счёта (`ScoreText`), префикс `Монет: `, подключите значение из `Score`.
     * Второй блок **`Set UI Text`**: выберите текст кнопки прокачки (`UpgradeBtn`), префикс `Улучшить (+1) | Цена: `, подключите значение из `UpgradeCost`.

Теперь при нажатии на вторую кнопку монеты списываются, клик в первой кнопке даёт больше монет, а цена прокачки растёт! 🐱💰

---

### Шаг 6. Пассивный доход (Автокликер)
Хотите, чтобы очки начислялись автоматически каждую секунду?
1. Добавьте ноду **`On Timer Tick`** (срабатывает раз в секунду).
2. Подключите:
   - `Get Variable (Score)` + `Get Variable (PassiveIncome)` через ноду **`Add`**.
   - Результат сохраните в `Set Variable (Score)`.
   - Вызовите **`Set UI Text`** для обновления `ScoreText`.
3. Теперь при покупке помощников (например, авто-котиков) просто увеличивайте переменную `PassiveIncome`!
