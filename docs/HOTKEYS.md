# ⌨️ Горячие клавиши Moewshare

На **Windows** основная клавиша команд — `Ctrl`, на **macOS** — `⌘ Command`.
В редакторе полный список всегда под рукой: **F1** или меню **Справка → Горячие клавиши** (есть поиск, колонка вашей ОС подсвечена).

## Редактор — общие

| Действие | Windows | macOS |
|---|---|---|
| Сохранить сцену | Ctrl+S | ⌘S |
| Отменить | Ctrl+Z | ⌘Z |
| Повторить | Ctrl+Y · Ctrl+Shift+Z | ⇧⌘Z |
| Открыть сцену | Ctrl+O | ⌘O |
| Настройки движка | Ctrl+, | ⌘, |
| Светлая / тёмная тема | Ctrl+Shift+L | ⇧⌘L |
| Справка по клавишам | F1 · Ctrl+/ | F1 · ⌘/ |
| Запустить / остановить игру | F5 · Ctrl+P | F5 · ⌘P |
| Остановить игру | Shift+F5 | ⇧F5 |
| Собрать для Web | Ctrl+B | ⌘B |

## Объекты сцены

| Действие | Windows | macOS |
|---|---|---|
| Добавить объект… | Ctrl+Shift+A | ⇧⌘A |
| Выделить всё | Ctrl+A | ⌘A |
| Добавить к выделению | Ctrl / Shift + клик | ⌘ / ⇧ + клик |
| Снять выделение | Esc | Esc |
| Копировать / Вырезать / Вставить | Ctrl+C / X / V | ⌘C / X / V |
| Дублировать | Ctrl+D | ⌘D |
| Удалить | Delete | ⌫ · ⌘⌫ |
| Переименовать | F2 | F2 |
| Скрыть / показать | H | H |
| Граф логики объекта | Ctrl+Shift+E | ⇧⌘E |

## Трансформация и камера

| Действие | Клавиши |
|---|---|
| Выбор / Перемещение / Вращение / Масштаб | Q / W / E / R |
| Фокус на объекте | F |
| Полёт камеры | ПКМ + W A S D, Q/E — вниз/вверх, Shift — быстрее |
| Орбита | Alt (⌥) + ЛКМ · СКМ |
| Панорама | Shift + СКМ |
| Зум | колесо мыши |

## Редактор событий (Event Graph)

| Действие | Windows | macOS |
|---|---|---|
| Выделить рамкой | ЛКМ по пустому месту и тянуть | то же |
| Добавить / убрать из выделения | Shift / Ctrl + клик | ⇧ / ⌘ + клик |
| Выделить все блоки | Ctrl+A | ⌘A |
| Удалить выделенные | Delete · Backspace | ⌫ |
| Копировать / Вырезать / Вставить | Ctrl+C / X / V | ⌘C / X / V |
| Дублировать | Ctrl+D | ⌘D |
| Создать группу из выделенных | Ctrl+G | ⌘G |
| Расформировать группу | Ctrl+Shift+G | ⇧⌘G |
| Сдвиг выделенных | стрелки (Shift — крупный шаг) | то же (⇧) |
| Показать все / выделенные | F · Shift+F | F · ⇧F |
| Масштаб 100% / + / − | Ctrl+0 / Ctrl+= / Ctrl+− | ⌘0 / ⌘= / ⌘− |
| Панорама | ПКМ/СКМ + тянуть · Пробел + ЛКМ | то же |
| Каталог блоков в точке | двойной клик по полотну | то же |
| Контекстное меню | ПКМ без перетаскивания | ПКМ · ⌃+клик |

Группа — цветная рамка вокруг блоков. Тяните её заголовок, чтобы двигать все блоки разом; название и цвет меняются в панели «Свойства».

## Лаунчер

| Действие | Windows | macOS |
|---|---|---|
| Вкладки Главная / Проекты / Шаблоны / Библиотека | Ctrl+1…4 | ⌘1…4 |
| Новый проект | Ctrl+N | ⌘N |
| Добавить существующий проект | Ctrl+O | ⌘O |
| Поиск по проектам | Ctrl+F | ⌘F |
| Настройки | Ctrl+, | ⌘, |
| Светлая / тёмная тема | Ctrl+Shift+L | ⇧⌘L |
