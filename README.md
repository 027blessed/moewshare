# 🐾 Moewshare Engine 0.1

Полноценная среда разработки игр: милый и быстрый **Лаунчер**, интерактивный **3D-редактор проектов** с гибкими перемещаемыми вкладками и **Web-рантайм** на Babylon.js.

- **Язык & Платформа:** C#, .NET 10, Avalonia UI 11 (MVVM).
- **Поддерживаемые ОС:** macOS (Apple Silicon M1/M2/M3/M4 arm64 и Intel x64), Windows 10/11 x64.
- **Целевой игровой рантайм:** Web (Babylon.js) с изолированным локальным HTTP-сервером.
- **Дизайн:** Нежно-розовая палитра, котик-маскот, округлые панели. **Светлая и тёмная темы** (Ctrl+Shift+L / ⇧⌘L).
- **Горячие клавиши:** Ctrl на Windows, ⌘ на macOS — полный список в [`docs/HOTKEYS.md`](docs/HOTKEYS.md) и в редакторе по F1.

## 🎮 Возможности Редактора Moewshare Engine

### 1. 3D-Сцена и навигация («как в других движках»)
- **Режим полёта (WASD + мышь):** зажмите **Правую Кнопку Мыши (ПКМ)** и осматривайтесь мышью.
  - `W` / `S` — полёт вперёд / назад
  - `A` / `D` — стрейф влево / вправо
  - `Q` / `E` — спуск вниз / подъём вверх
  - `Shift` — ускорение полёта (в 2.5 раза)
- **Орбитальный осмотр:** зажмите `Alt` + ЛКМ (или среднюю кнопку мыши) для вращения камеры вокруг объекта/сцены.
- **Панорамирование (Pan):** зажмите `Shift` + СКМ / ПКМ для перемещения плоскости вида.
- **Приближение (Zoom):** колёсико мыши.
- **Фокус на объекте (`F`):** мгновенно центрирует камеру и подлетает к выбранному объекту.
- **Пресеты вида:** кнопки `3D`, `Сверху`, `Спереди`, `Сбоку`.

### 2. Трансформации объектов и горячие клавиши (Гизмо)
- `W` — **Перемещение (Translate):** 3D-стрелки X (красная), Y (зелёная), Z (синяя) для интерактивного перетаскивания объекта мышью.
- `E` — **Вращение (Rotate):** кольца вращения вокруг осей X, Y, Z.
- `R` — **Масштабирование (Scale):** манипуляторы масштаба по осям и центральный куб для равномерного масштабирования.
- `Q` — **Выбор (Select):** режим без отображения гизмо.
- `Ctrl+D` / `Cmd+D` — **Дублировать объект**.
- `Delete` / `Backspace` — **Удалить объект**.
- `Ctrl+S` / `Cmd+S` — **Сохранить сцену**.
- `F5` / `Ctrl+P` — **Запустить / Остановить игру**.

### 3. Перемещаемые вкладки (Гибкий Докинг)
Все панели редактора можно перемещать куда угодно для максимального удобства:
- **🐾 Иерархия** (объекты сцены, добавление Куба, Сферы, Цилиндра, Плоскости, Света)
- **🎨 Инспектор** (трансформация, цвет, текстура, физика, поведение)
- **🎬 Сцена 3D** (интерактивный 3D-вьюпорт)
- **📁 Ресурсы** (проводник файлов, импорт ресурсов)
- **📜 Консоль** (логи, фильтры ошибок/предупреждений/инфо, очистка)
- **🚀 Запуск & Web** (управление локальным сервером и сборкой)

У каждой вкладки есть кнопки перемещения в шапке:
- `[⇦]` — переместить в левую колонку
- `[⇩]` — переместить в нижнюю панель
- `[⇨]` — переместить в правую колонку
- `[⛶]` — переместить в центр
Кнопка **«⊞ Сброс панелей»** в тулбаре возвращает стандартную раскладку в один клик.

### 4. Выбор цветов и импорт текстур
- **Палитра цветов:** быстрые пресеты приятных пастельных цветов (Moew Pink, Light Rose, Pastel Mint, Sky Blue, Lavender, Wood, White, Slate), ручной ввод `#RRGGBB` и интерактивный предпросмотр.
- **Импорт текстур:** кнопка «📁 Выбрать файл…» позволяет импортировать PNG, JPG, WebP и сразу назначить текстуру на выбранный объект.
- Babylon.js рантайм на лету накладывает выбранную диффузную текстуру (`diffuseTexture`) на 3D-модель объекта.

### 5. Консоль и диагностика
- Логирование событий движка с цветовой маркировкой (ℹ️ Инфо, ⚠️ Предупреждения, ❌ Ошибки, ✅ Успех).
- Фильтры по уровням сообщений и счётчики ошибок.
- Быстрая очистка консоли кнопкой «🗑 Очистить».

## 🛠 Сборка и запуск

### Запуск из исходного кода:
```bash
# Лаунчер Moewshare
dotnet run --project src/Moewshare.Launcher

# Редактор напрямую (с указанием пути к проекту)
dotnet run --project src/Moewshare.Editor -- --project "/путь/к/папке/проекта"
```

### Запуск тестов:
```bash
dotnet test
```

### Сборка для macOS (Apple Silicon arm64):
```bash
./build-macos.sh osx-arm64
```
Скрипт собирает готовые `.app`-бандлы и ZIP-архив в `dist/`:
- `dist/osx-arm64/Moewshare.Launcher.app`
- `dist/osx-arm64/Moewshare.Editor.app`
- `dist/Moewshare-osx-arm64.zip`
- Редактор автоматически регистрируется в `~/Library/Application Support/Moewshare/Editors/0.1.0`.
Для запуска:
```bash
open dist/osx-arm64/Moewshare.Launcher.app
```

### Сборка для Windows x64:
На Windows:
```powershell
.\build-windows.ps1
```
Или кросс-платформенная сборка из любой ОС:
```bash
dotnet publish src/Moewshare.Launcher -c Release -r win-x64 --self-contained true -o dist/win-x64/Moewshare
dotnet publish src/Moewshare.Editor -c Release -r win-x64 --self-contained true -o dist/win-x64/Moewshare/Editors/0.1.0
```
Готовый ZIP-архив: `dist/Moewshare-win-x64.zip`.

## 📁 Структура создаваемого проекта игры

```
MyGame/
├── project.json              # Конфигурация игры (название, шаблон, стартовая сцена)
├── index.html                # Точка входа в браузере
├── README.md                 # Документация проекта игры
├── Scenes/
│   └── Main.scene.json       # Описание сцены (объекты, трансформы, материалы, физика)
├── Assets/
│   ├── Textures/             # Текстуры (.png, .jpg, .webp)
│   ├── Models/               # 3D-модели (.glb, .gltf, .obj)
│   └── Audio/                # Звуки (.mp3, .wav, .ogg)
├── Scripts/                  # Папка для скриптов (C# запланирован)
├── Runtime/
│   └── moewshare-runtime.js  # Браузерный рантайм на Babylon.js
└── Build/
    └── web/                  # Готовый экспорт для Web-хостинга
```
